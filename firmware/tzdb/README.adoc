= WGS84 position to time zone

airgrep uses a GNSS position to look up the local IANA time zone and display local time offline.

== Build and install

Allow several GB of RAM and disk space for the default build.
Run from `firmware/tzdb`:

[source,sh]
----
cmake --workflow --preset tzdata         # build build/tzdata.bin, run the tests
cmake --workflow --preset tzdata-flash   # build, flash when the device holds another table
----

A tagged boundary release is downloaded once into `data/`, pip reuses its wheel cache, and the table is rebuilt only when a tool, the requirements or a setting change.

In airgrep Utility, connect to the device and choose *Time Zone Data…* under *Maintenance* to install `build/tzdata.bin`.
From the command line, `tools/airgrep.py flash-tzdata tzdb/build/tzdata.bin` installs it, `--force` also when the device holds it already.

== Choosing a resolution

The default grid uses 0.01° cells.
Configure CMake with `-DCELL=0.02` for a smaller table.

[cols="2,1,2,1",options="header"]
|===
| Resolution | Cell width at the equator | Maximum distance to cell center | Size
| Original polygons (losslessly compressed) | N/A | N/A | 83.57 MB
| 0.01° | 1.11 km | 0.79 km | 1.75 MB
| 0.02° | 2.23 km | 1.57 km | 0.83 MB
|===

Each cell uses the time zone at its center, so borders are approximate and narrow zones can disappear.

== Clock rules

The POSIX rules in this table describe clock changes for 2026.
For a different year, regenerate and check the rules against IANA tzdata.
`Africa/Casablanca` and `Africa/El_Aaiun` have three offset changes in 2026, more than one POSIX rule can express.
The table retains both names and airgrep displays UTC in those zones.

= airgrep firmware and macOS Utility

The airgrep Firmware and macOS Utility application.

== Layout

[cols="1,2",options="header"]
|===
| Component
| Description

| link:version.txt[`version.txt`]
| Version string

| link:main/[`main`]
| Main ESP32 Firmware code

| link:components/[`components`]
| airgrep system components, daidalus integration, LVGL frontend, Hardware tests, Event Loop

| link:tools/[`tools`]
| airgrep.py Command-Line interface, flash, checks and cleanup

| link:tzdb/[`tzdb`]
| Builds the time zone table for GNSS positions.

| link:utility/[`utility`]
| macOS Utility application
Firmware upgrade, Device information, debug console

|===

== Build Environment

The firmware and the utility build independently.
The utility is a macOS application.

[cols="1,3",options="header"]
|===
| Target
| Needs

| Firmware
| ESP-IDF v6.1, which brings CMake, Ninja and Python, and the esp-clang of its tools, which has the compiler and clang-tidy. Git and clang-format.

| Utility
| ESP-IDF v6.1 Component Manager for LVGL, CMake 3.27, Ninja, the Xcode Command Line Tools, libusb, pkg-config, Python, clang-format and clang-tidy from LLVM.

| Checks
| Ruff, ShellCheck, a C and C++ compiler for the host tests. On macOS also Pillow for the display checks.

|===

=== Setup

.macOS
[source,bash]
----
xcode-select --install
brew install cmake ninja clang-format llvm libusb pkgconf python pillow ruff shellcheck
brew install espressif/eim/eim
eim install -i v6.1
----

.Linux
[source,bash]
----
sudo apt-get install git clang-format shellcheck python3 pipx build-essential
pipx install ruff
----

Install ESP-IDF v6.1. If esp-clang is missing, run `idf_tools.py install esp-clang` in the ESP-IDF environment.

== Development

.Firmware, from `firmware/`
[source,bash]
----
source ~/.espressif/tools/activate_idf_v6.1.sh    # once per shell
cmake --workflow --preset s3-flash                # build, flash, open the console
cmake --build --preset s3-flash                   # the same, without configuring again
----

.Typical build for Display and Debug development
[source,bash]
----
cmake --workflow --preset s3+800x480-touch+debug-flash
----

Each preset in link:CMakePresets.json[CMakePresets.json] has a build workflow and a `-flash` workflow.
Flashing puts the device into its bootloader over USB and opens the console afterwards. `AIRGREP_SERIAL` selects a device by its factory MAC.

A preset is the `s3` board plus `+` mixins, one sdkconfig fragment each.
A new combination is one line in `configurePresets`, `"inherits": ["s3", "+800x480-touch", "+debug"]`, plus its build and workflow entries.

[cols="1m,3",options="header"]
|===
| Mixin | Adds

| `+800x480-touch`
| A https://www.waveshare.com/4.3inch-capacitive-touch-lcd.htm [4.3inch Capacitive Touch LCD, 800x480 display]

| `+service`
| USB service commands for Remote Display, Show Data and the settings reset of the Utility

| `+debug`
| Debug controls that cost time, the LVGL draw profiler

| `+uart0`
| Console on UART0, GPIO1 and GPIO2

| `+hwtest`
| Hardware test mode

| `+test`
| On-device tests

|===

.Utility, from `firmware/utility/`
[source,bash]
----
cmake --workflow --preset utility-macos           # build, run the host tests
ctest --preset utility-macos -L display           # one group: display, firmware, device, lint or docs
open "build/airgrep Utility.app"
----

== Debugging

The ESP32-S3 debugs over the built-in JTAG of its USB port, which TinyUSB takes over in the normal firmware.
Flash a `+test` or `+uart0` build to keep the USB port on JTAG, then attach OpenOCD with `board/esp32s3-builtin.cfg`.

WARNING: External JTAG probes (e.g. ESP-Prog) on GPIO39 to 42 requires an eFuse burned 🔥 (`STRAP_JTAG_SEL`, `DIS_USB_JTAG`), which can't be undone and therefore, this is our least favorite option.

* https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-guides/jtag-debugging/index.html[ESP-IDF JTAG debugging]
* https://docs.espressif.com/projects/vscode-esp-idf-extension/en/latest/debugproject.html[VS Code]
* https://www.jetbrains.com/help/clion/esp-idf.html[CLion].

=== Wrap up

* `tools/check.sh`: Builds `s3`, `s3+service`, `s3+800x480-touch` with and without `+debug`, and `s3+test` and runs every host test.
* `cmake -P tools/clean.cmake` deletes all build directories.

== Flashing

`cmake` builds firmware images at link:build/images/[`build/images/`].
Use either the macOS Utility or `airgrep.py` to flash the firmware or the Timezone database:

[source,bash]
----
# which the `-flash` workflows run
tools/airgrep.py flash build/images/airgrep-<preset>.bin

# alternative to cmake --workflow --preset tzdata-flash from tzdb/
tools/airgrep.py flash-tzdata tzdb/build/tzdata.bin
----

For a device that no longer boots: `$ tools/airgrep.py bricked`.

# Portable ADS-B / FLARM receiver carrier PCB

A carrier board for three plug-in modules: an ESP32-S3 touch display, an ADSBee 1090U receiver and a GNSS module. It adds a single-cell Li-ion charger, a 5 V boost rail, a fuel gauge, a barometer and a buzzer.

## Current state

- Schematic (7 sheets) and board (105 x 95 mm, 4 layers, all SMD parts on top) are complete. `tools/check.sh` reports the ERC, DRC and parity state.
- Order status and open work are in [docs/open-issues.md](docs/open-issues.md).

## Tools

- KiCad 10.0.6, including `kicad-cli` and its bundled Python for the scripts that use `pcbnew`. `tools/kpy` runs that Python.
- Python 3.14; the simulation packages are listed in `hardware/sim/requirements.txt`
- ngspice 47 (Homebrew) for `hardware/sim/`
